## اختبارات المتصفح القابلة للإعادة

الملف `scripts/verify-unit-1-lessons.mjs` يفحص السلوك فعليًا باستخدام Playwright وChromium. أدوات الاختبار مثبّتة مؤقتًا بـ `--no-save --package-lock=false`، وليست اعتماديات تطبيق جديدة. لا تغيير في `package.json` أو القفل.

```sh
npm ci
npm install --no-save --package-lock=false @playwright/test @sparticuz/chromium
npm run build
npm run preview
# في طرفية منفصلة؛ قُسمت الجولات لتفادي مهلة بيئة التنفيذ:
LESSONS=2,3 node scripts/verify-unit-1-lessons.mjs
LESSONS=4 node scripts/verify-unit-1-lessons.mjs
LESSONS=5,6 node scripts/verify-unit-1-lessons.mjs
```

في بيئة هذه المهمة كانت مكتبات NSS/NSPR النظامية غير موجودة. استُخرجت مكتبات `al2023.tar.br` المضمنة في حزمة Chromium إلى `/tmp/chromium-libs/lib` وشُغّلت الأوامر مع `LD_LIBRARY_PATH=/tmp/chromium-libs/lib`. أزيل خيار `--single-process` من تشغيل متصفح الاختبار. هذه إعدادات أدوات التحقق فقط وليست تعديلًا للتطبيق.

نتائج الجولات الناجحة محفوظة محليًا في:
- `test-results/unit-1/browser-results-2,3.json`
- `test-results/unit-1/browser-results-4.json`
- `test-results/unit-1/browser-results-5,6.json`

جولات سابقة اصطدمت بمهلة التنفيذ عند تشغيل كل الدروس معًا أو بالتوازي. الجولات النهائية المنفصلة خرجت جميعها بالكود 0. اختبار الروابط المباشرة يغادر المستند أولًا ثم يفتح الرابط في مستند جديد، لتمييز اختبار الفتح المباشر عن تنقل البصمة داخل المستند؛ السابق/التالي مختبران منفصلًا.

## الطباعة الفعلية

- أنشئت خمسة ملفات PDF فعلية باستخدام Chromium `page.pdf`، وليس مجرد محاكاة CSS.
- أُعيد توليدها بعد آخر تعديل لفواصل العناوين.
- أسماء الملفات: `test-results/unit-1/lesson-N-notebook.pdf` للأرقام 2–6.
- فحص `scripts/verify-unit-1-pdfs.py` باستخدام PyMuPDF: الصفحات كلها A4، لا صفحات خالية، ولا نصوص مستخرجة خارج حدود الأمان. توجد مسارات متجهة فعلية للرسوم والجداول.
- عوينت صور تجمع **جميع صفحات كل دفتر** للتحقق بصريًا من تدفق المحتوى والرسوم، بالإضافة إلى معاينة مكبرة لصفحات من دفاتر الأعداد والخطوط.
- فحص المتصفح لم يجد تجاوزًا في الجداول أو المعادلات أو SVG داخل الدفتر. أزرار التنقل غير ظاهرة في وضع الطباعة.
- تفاصيل الأعداد وحدود النصوص: `test-results/unit-1/pdf-results.json`.
- ملفات PDF واللقطات مخرجات تحقق محلية ضمن المجلد المتجاهَل `test-results/`، وليست أصولًا تُنشر مع التطبيق.

```sh
# PyMuPDF أداة تحقق اختيارية، لا اعتمادية للموقع
python scripts/verify-unit-1-pdfs.py
```

## الإصلاحات التي كشفها التحقق

1. تسجيل المكونات العميلة بأسمائها صراحة بدل نشر كائن مُصدّر من ملف client في سجل server؛ كان البناء وحده لا يكشف النشاط غير المسجّل.
2. تخفيف padding أزرار التنقل عند 360px للدروس المضافة فقط، دون تغيير الترتيب أو السلوك.
3. لف الصيغ التفصيلية الطويلة في KaTeX إلى سطرين دون حذف أي حد.
4. ضبط عرض الجداول وهوامش A4، وإضافة تجنب فواصل داخل كتل الدفتر ورسوماته، ومنع الفقرة الفارغة من فصل العنوان عن المحتوى.
5. مراجعة مواضع علامات التعامد والتسميات داخل SVG وتجنب قص تسميات رؤوس الشكل ABCD.

## حدود التحقق

- المعاينة آلية في Chromium مع لقطات بصرية؛ ليست تجربة على هاتف فعلي أو اختبار Safari/Firefox.
- الطباعة إلى PDF فعلية؛ لم تُجرّب طابعة ورقية.
- فحص حدود PDF ومعاينته لا يعوض مراجعة بشرية تربوية تفصيلية لكل حرف مقابل الصور؛ ملف خريطة المصدر وأرقام الصفحات مرفقان لتيسير هذه المراجعة.
- لم يُختبر الموقع المنشور بعد التغيير، لأن النشر والدمج ممنوعان في هذه المهمة.
